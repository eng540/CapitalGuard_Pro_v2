# TG-03 — واجهة Web لقراءة توصيات المتداول

**الحالة:** `BUILD_DONE` — بانتظار UAT لجلسة Telegram حقيقية.  
**النطاق:** قراءة Core فقط؛ لا توجد أوامر close/partial/entry/SL أو نشر أو دفع أو تنفيذ آلي.

## العقد

Web SaaS يستدعي Core من الخادم عبر Core service key ولا يرسلها إلى المتصفح. يُشتق Telegram ID من جلسة Web المصادق عليها خادمياً، ثم يعيد Core قائمة `USER_TRADE` مع `schema_version` و`as_of` و`public_ref` و`display_ref` و`source`.

تستدعي شاشة التفاصيل المسار المملوك حسب `public_ref` فقط. يعيد Core التفاصيل إن كان الصف مملوكاً للمتداول، أو `404` بلا كشف ما إذا كان المرجع يخص مستخدماً مختلفاً. الترميز `encodeURIComponent` في Web مع converter `path` في Core يدعمان المرجع الهرمي الذي يتضمن `/`.

## سلوك الواجهة

تعرض صفحة التوصيات المصدر عند وجوده، وتفتح لوحة تفاصيل قراءة فقط. حالات التحميل والخطأ لا تستبدل بيانات Core ببيانات محلية، وتوضح الواجهة أن التنفيذ غير متاح في هذا المسار.

## قبول TG-03

اجتازت اختبارات Vitest لعقد Adapter وTypeScript. يلزم UAT بجلـسة Telegram حقيقية لإثبات أن فتح تفاصيل مرجع يخص المستخدم ينجح وأن مرجع مستخدم آخر لا يظهر في WebApp.
