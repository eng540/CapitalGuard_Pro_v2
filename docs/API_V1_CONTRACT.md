# CapitalGuard API v1 Contract

**الإصدار:** `v1`  
**الحالة:** ركيزة R4 غير تجارية؛ لا تمثل واجهة تداول أو اشتراك أو Copy Trading.

## النطاق الحالي

| المسار | المصادقة | الاستخدام | البيانات المحظورة |
|---|---|---|---|
| `GET /api/v1/status` | عامة | التحقق من readiness وإصدار العقد | المستخدمون، الحسابات، التوصيات، الصفقات، PnL، التاريخ، القنوات، الـ API keys، وإعدادات الأسرار. |

يعيد المسار عند الجاهزية: `api_version` و`service` و`status` و`commercial_mode=noncommercial`. ويعيد HTTP `503` قبل اكتمال Core readiness. لا يستبدل هذا المسار `/health`؛ إذ يبقى `/health` عقد البنية التحتية، بينما `/api/v1/status` هو عقد منصة مَصدّر ومُرقّم.

## حدود التوسع

أي مورد مالي أو مملوك لمستخدم يتطلب عقداً منفصلاً، مصادقة مناسبة، scoped authorization، rate limit، اختبارات tenant/ownership، وتوثيق migration/rollback. لا يُضاف أي endpoint للصفقات أو المدفوعات أو التنفيذ إلى v1 تحت قرار R4 الحالي.

## اختبارات القبول

تغطي `tests/test_api.py` فشل الجاهزية الآمن، الاستجابة المَصدّرة عند الجاهزية، وثبات حمولة غير مالية فقط. يظل load test وrate limit وtenant boundary أدلة مفتوحة لبوابة R4 الكاملة.
